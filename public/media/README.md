# Birthday Memory Video

Place your birthday video here or host it on a cloud storage provider / CDN.

- **Local Path**: `/media/jeevuhhhh-birthday-video.mp4`
- **Remote URL**: You can set `birthdayVideoPath` in `src/config/siteConfig.ts` to any direct HTTPS MP4 URL (e.g. Supabase Storage, Cloudinary, Vercel Blob, Google Drive direct stream, or unlisted stream).
