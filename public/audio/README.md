# Audio Assets Folder

Place your audio MP3 files in this directory:

1. `background-music.mp3`
   - Plays softly across the website after the initial door unlock gesture.
   - Recommended format: MP3, 128kbps or 192kbps, continuous pleasant instrumental loop.
   - Default volume: 0.10 (10% mild background volume).

2. `door-open.mp3`
   - Plays once when the secret door unlocks.
   - Recommended format: MP3, magical door creek or celestial chime sound effect.
   - Default volume: 0.10 (10% mild level).

3. `gift-open.mp3`
   - Plays when the visitor taps to open the 3D gift box.
   - Recommended format: MP3, celebratory sparkle / party popper burst.
   - Default volume: 0.10 (10% mild level).

4. `wish-reveal.mp3`
   - Plays when a new celestial star wish is tapped and revealed.
   - Recommended format: MP3, gentle chime / music box bell tone.
   - Default volume: 0.10 (10% mild level).

> Note: If any audio file is absent, the application gracefully provides subtle synthesized tones or continues silently without throwing errors.
